# 0.6.54 parity preview 1

以 `005e0a0` / 0.6.53 為基線，保留防重複掉落、原生輸入模式及告示牌手持修復。

- 還原 25 款飲品共 97 個瓶數形狀、15 種杯、雪克杯、酒桶外緣的碰撞；按照 Java 原始碼轉換座標與朝向。
- 縮小選取範圍至實際 Java 形狀的包圍盒。三瓶聯集形狀的凹位仍可被準星選中，因選取元件僅支援單盒；實體碰撞保留凹位。
- 微醺偏航替代預設關閉，避免自動改變瞄準。玩家可用 `/function kt_tipsy_motion_on` 明確啟用，`/function kt_tipsy_motion_off` 關閉；尚未還原 Java 的純鏡頭 roll。
- 尖嘯允許命中生存／冒險玩家，遵守世界 `pvp`；創造／旁觀玩家免疫。保留原生傷害檢查及目標上限。
- 指南說明长臂的實際作用範圍、微醺預設行為、尖嘯 PvP 規則。

完整證據、剩餘差距及驗收方式見 [PARITY-REPAIR-0.6.54.md](PARITY-REPAIR-0.6.54.md)。此為測試候選包，尚未部署至 managed-server。
