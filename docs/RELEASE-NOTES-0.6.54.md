# 酒館 0.6.54 — 修復釀酒指南並核對廚房章節接收

- 修正酒桶頁「開蓋取成品」的錯誤指示：成品存在時桶蓋鎖定，空瓶須放酒嘴正下方，以空手開酒嘴取酒；品質 1 就能裝瓶。
- 補上標準熟成階段 2／4／6／8／10 分鐘、合計約 30 分鐘及區塊載入條件。
- 28 個內部舊指南頁保留 ID，但文字改從現行廚房章節產生，清除舊兩次點擊模式及過時效果說明。
- 果盆、酒嘴及雪克杯的聲音呼叫失敗現在會保留診斷並限頻記錄，避免靜默失敗；成功呼叫不宣稱玩家已聽到。
- 指南診斷明確區分未找到廚房、正在傳送、已發送但未確認。廚房 API v1 沒有接收回執，測試以隔離 BDS 直接讀取廚房接收器確認。

驗證紀錄見 `GUIDE-REPAIR-0.6.54.json`。客戶端聲音、手部動畫、觸控／手柄及鏡頭近似仍需真實客戶端驗收。
