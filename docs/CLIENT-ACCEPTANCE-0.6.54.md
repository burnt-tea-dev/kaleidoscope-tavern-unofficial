# 0.6.54 客戶端驗收清單

狀態：全部待真實玩家驗收。本次未登入 Minecraft 客戶端。每項須記錄裝置、控制方式、語言、影片時間碼及成功／失敗；鍵鼠、觸控、手柄各跑一次。不可把伺服器 API 呼叫成功填為實機通過。

| 操作 | 驗收標準 |
|---|---|
| 首次持有指南及舊書轉換 | 以森羅廚房指南開啟酒館章節；返回分類正常，舊書轉換後可再次開啟 |
| 三語章節 | 繁中、簡中、英文均可讀酒桶、酒嘴、雪克杯、配方與效果，無截斷 |
| 首瓶酒 | 新角色只跟指南投四桶同種液體、等量配料、關蓋、装酒嘴、嘴下擺瓶、空手取 Q1；不用額外口頭指示 |
| 果盆 | 踩踏成功／失敗／完成聲音有位置感；粒子與八方向退料正確，扣還物一致 |
| 酒桶 | 液面與配料可見，關蓋有回饋，批次存在時不可開蓋；HUD 顯示產品、數量、品質和剩餘時間 |
| 熟成 | 載入區塊內以實際倒數為準；Q1 至 Q6 各段 2/4/6/8/10 分鐘，提前裝瓶停止熟成 |
| 酒嘴 | 開關聲、滴液與裝瓶完成回饋；錯誤／缺少容器不吞物，擺瓶與掉落容器均核對 |
| 雪克杯 | 三槽投料、拿起、按住、放開、倒酒全鏈；長按聲不重疊失控，完成音、手部與杯蓋動畫同步 |
| 展示與收納 | 四朝向逐格放／取、酒架彈出聲；點中物與取出物一致，重進仍保留 |
| 家具 | 高腳凳／沙發上下座正常；展板文字、玻璃、燈光可讀；手持展板及冰櫃放置朝向正常 |
| 特殊效果 | 靈視聲與畫面、微醺鏡頭、隱匿及觸及逐項測；記錄基岩適配限制，不填 Java 完全等同 |
| 多人與重進 | 兩玩家同時操作不複製／吞物、聲音距離合理；離開區塊與重進保留機器狀態 |

微醺真正的鏡頭 roll、草叢隱匿及延伸觸及的 Java 全域行為仍屬基岩適配差距；此修正版沒有宣稱解決 API 能力差異。
