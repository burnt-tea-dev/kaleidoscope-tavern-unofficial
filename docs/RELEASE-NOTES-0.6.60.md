# 0.6.60 interaction preview 1

整合 0.6.59 主線 `d6b2674` 的酒液表面修復與本輪互動修復。

- 取回同款同品質酒時，自動合併已有堆疊。新舊的酒館品質說明會先正規化比較；自訂名稱、說明、原生限制和特調資料不會被抹掉。
- 空手取物優先使用其他空欄，讓選中的欄位維持空手，便於連續取酒；只有其他位置沒有空位時才使用手中欄。
- 同一次放置的重複原生事件只執行一次，避免放下雞尾酒後第二個回呼報 `STALE_HAND`；剛放好的杯子也不會被緊接的空手回呼取走。
- 黑板水平對齊：靠左、置中、靠右、左右／兩端對齊（段末行靠左）、分散對齊。垂直對齊：靠上、置中、靠下。
- 小黑板最多 11 行，每行最多 10 半角或 7 全角；混排同時受容量與字型像素寬度限制。大黑板保留原有較寬版面。立式告示牌保留 8 行。
- 編輯框可輸入 `\n` 換行，超出容量會拒絕此次儲存並保留舊文字，不再靜默截斷。

驗證與實機限制見 [INTERACTION-REPAIR-0.6.60.md](INTERACTION-REPAIR-0.6.60.md)。本包未部署至 managed-server。
