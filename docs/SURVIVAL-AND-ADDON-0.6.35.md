# 0.6.35 生存入口與附屬審核

## 森羅酒館植物

官方 Java 酒館只有野生葡萄藤一條自然植物來源。橡樹、樺樹樹冠下的野生藤可採收；隨後在棚架上培養普通、冰、金三種葡萄，並由果實壓榨啟動酒桶。基岩生成規則取 oak/birch 葉為頂面錨點，搜尋樹冠下方 24 格；它在森林、平原、草甸中註冊。Java 在不同樹形使用多組概率，基岩 Feature API 的分布規則是近似實現。這項檢查確認來源與載入無錯，未測得實際世界每棵樹的生成頻率。

額外的藤蔓+甜莓起始合成已刪除。Bedrock 的 `minecraft:snow`、`minecraft:magma` 已納入冰／金葡萄的種植土壤識別。其餘果實採集與釀造使用既有酒館流程。世界名酒附屬不增加新的野生植物；配方使用上述葡萄、原版植物及森羅廚房的水稻供應鏈。

## 附屬接口

基礎包將外部品質酒的六個物品 ID、最大擺放數、材質模型、品質效果、酒架用瓶子視覺及可用的杯裝雞尾酒加入同一註冊資料。附屬卸載時可解除註冊。原生酒款維持原來的 ID；外部酒款保留自己的命名空間。最多 192000 位元組的註冊訊息以線性掃描分包，在 1.26.51.1 專用伺服器完成收發。

## 審核界線

沒有模擬玩家互動。專用伺服器接受資源定義、配方、組件與腳本並回覆註冊成功；此檢查無法證明手機端透明杯身、牆面模型朝向、音效與特效視覺。世界名酒的 Brew Accelerator 原版自訂附魔，以及僅由 Java 客戶端提供的 Hostile Detection/Treasure Sense 輪廓和倒置鏡頭，仍列在附屬預覽包的限制中。
