# 0.6.36-beta.1 — 香薰粒子與效能修正

- 香薰小粒子改用 Bedrock 原生初速度與動態運動，不再依賴逐影格 Molang 位移迴圈。
- 大型香薰粒子有可見的運動，縮短網路粒子存活時間，且每個方塊每秒最多送出兩個大型粒子，減少多人伺服器堆積。
- 維持酒館擴充接口；世界名酒 0.1.1 預覽版會透過該接口註冊酒桶、雪克杯、酒瓶及雞尾酒。
- 深水炸彈、下界特調的物品圖標改回 Java 動畫貼圖；特調雞尾酒改用原版玻璃底圖和只染液體的遮罩，創造物品預設色仍為 Java 的 `#5555ff`。
- 沙發轉角保留兩側靠背碰撞，移除座面碰撞；葡萄藤修剪及成熟葡萄剪取補上剪切音效。
- 圖鑑的螢光莓與甜莓壓榨條目補齊繁中、簡中、英文標題。

已完成靜態資產、腳本與語言檢查。基岩專用伺服器只驗證載入，無法證明手機客戶端的粒子與畫面效果；這些仍需實機回報。
