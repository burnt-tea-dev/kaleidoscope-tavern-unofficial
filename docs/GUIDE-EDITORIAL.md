# 酒館指南文案與呈現

本輪參考原移植作者的 [Tavern 1.0.1](https://www.curseforge.com/minecraft-bedrock/addons/kaleidoscope-tavern-unoffical) 與 [Cookery 1.6.0](https://www.curseforge.com/minecraft-bedrock/addons/kaleidoscope-cookery-unofficial) 實際指南。沿用短標題、短段落和按需查製作方法的節奏；玩法說明仍核對目前 canonical runtime，避免照抄原包的矛盾或失效指示。

七個入口、子分類、單品及圖示沿用 `GUIDE-STANDARD.md`。酒館獨立指南和可選料理指南內的酒館章節，均開啟酒館同一份投影與顯示流程。料理宿主僅透過既有登記擴充交接玩家、語系及返回動作；其他章節保持原流程。舊版酒館未回應時回到原章節，關閉不自動重開料理指南。

設備先講放置／投料／啟動／取出，僅保留會影響操作與物品保存的限制。產品先講特色和實際用途；液體、數量、雪克杯槽位、容器及時間保留在該物品的「製作方法」。家具合成指向原版配方書，沒有虛構的配方卡。

主頁不展開六品質效果表、隨機概率、顏色運算或內部資料結構。必要門檻與平台未完成行為仍寫在相關單品，避免玩家白做操作。主動查看目前酒效的入口保留。沒有新增解鎖規則或隱藏已登記配方。

繁中、簡中、英文各自完整。金色粗體標題、灰色內文、段間空行及格式重置由共同顯示層處理，文案來源不混入 Markdown 或長篇 UI 說明。長度以用途判斷：一般物品短述，冰櫃與黑板等複合操作容許較多段落；不以截斷文字來達成長度限制。

本輪校正酒桶關蓋取酒及剩餘成品繼續熟成、葡萄結果空間、壓榨空桶取汁、雪克杯清空／時機、瓶架容器、香薰亡靈互動、黑板行寬／上蠟與家具回收。既有投影、配方及宿主檢查涵蓋兩入口和三語；SDK／無玩家 BDS 結果不等於真人閱讀、排版或按鍵操作驗收。

完整家族另登記 AMW 2.6.26 的 `amw:kirsch`、`amw:kriek`、`amw:sour_cherry`、`amw:sour_cherry_bucket` 四頁，合計 227 條目；Tavern／World Liquor 組合本身為 223。酒館共用投影對這四個精確 ID 追加三語文案適配：更正英文名稱及既有品質名稱，分開果實與果汁用途，將採收後再生寫為「葉片重新長出果簇後成熟」，兩酒保留用途與有效調酒門檻。酸櫻桃屬種植，果汁屬果汁，兩酒保留附屬釀造分類。原登記頁、配方、數量、熟成、效果、AMW 身份與檔案均不改。
