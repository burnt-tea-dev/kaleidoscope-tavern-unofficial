# 0.6.32 rc1

- 酒桶提示保留經驗欄上方的單行置中文字，移除外框和流動光點，分隔符改為 `  丨  `。
- 補上 Java 雪克杯倒出成品時的 20 個藥水效果粒子、神秘雞尾酒杯口持續飄出的效果粒子。
- 燃燒瓶飛行增加 Y／X 雙軸旋轉（每秒 400／280 度，含座標轉換），模型縮放由 0.65 改回 Java 的 0.5。
- 雪克杯搖晃只控制正在持杯的右臂，避免連左手一起抬起；搖晃音量與音高恢復 Java 的隨機範圍。
- 酒館資源包加入 `pbr` 相容宣告，特調酒液體圖集增加非金屬 PBR 表面設定。

詳見 [Java 動畫對照](JAVA-VISUAL-AUDIT-0.6.32.md) 及 [靈動視效部署說明](VIBRANT-VISUALS.md)。沒有執行模擬玩家互動；BDS 載入不能替代手機材質、動畫與靈動視效選項的實機驗收。
