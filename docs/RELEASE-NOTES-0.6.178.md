# Tavern 0.6.178 — barrel ice and online effect clocks

Ordinary ice in each of the four barrel ingredient slots now selects an alpha-blended material. The maintained Java renderer uses a translucent layer, and the matching ice texture contains alpha 190 throughout. Packed ice, blue ice and the other ingredient materials retain their previous routing; geometry, texture bytes, positions and animation remain unchanged. Source/material checks cannot establish the final client blend order or lighting.

The reviewed [Java barrel renderer](https://github.com/KaleidoscopeMods/KaleidoscopeTavern/blob/a1afba34981a00e89d57130d3dc8f1e64f1820a2/src/main/java/com/github/ysbbbbbb/kaleidoscopetavern/client/render/block/BarrelBlockEntityRender.java#L130) uses the fixed item renderer. The official Minecraft 1.21.1 client archive, SHA1 `30c73b1c5da787909b2f73340419fdf13b9def88`, binds ordinary ice to the translucent item render path. The matching Java and Bedrock ice RGBA SHA256 is `f5758a35b800ee7bf763234cdcb1ec2e7b4ea5c73da1623fb6962a6d167accfa`. Microsoft's [material documentation](https://learn.microsoft.com/en-us/minecraft/creator/documents/material-files?view=minecraft-bedrock-stable) distinguishes alpha testing from alpha blending.

Saved custom effects now start their online clock at the first successful read of a loaded entity handle. Previously, a player who joined with 100 ticks remaining and left four ticks later could retain all 100 ticks because no heartbeat had written an anchor yet. That sequence now saves 96 ticks; a later login excludes the offline interval. Read-only snapshots do not advance the persistence anchor, and replacing a handle with the same entity ID starts a new online interval. This changes the shared countdown, without changing the excluded tipsy visual adapter.

Five new production-callback counterexamples fail before the clock fix and pass after it. The existing 56-test efficiency suite passes. Ice checks distinguish the previous alpha-test route from the source-backed translucent selection for all four slots and preserve the other ingredient routes. These are source and deterministic API-double checks.

The candidate is paired with World Liquor 0.1.155, including its blue-dye freezer sprite and deferred interaction repairs. Canonical CI, complete-family static validation, a fresh consistent saved-world first load/restart and deployment admission remain required. `client=false`, `production_ready=false`, `pending_client_acceptance` remain in force; this document does not assert deployment or complete Java parity.

The inherited lossless NBT migration tool prevents future binary-string rewriting. Existing damaged storage actors still require a separately reviewed recovery; this release does not clear or replace their bindings.
