# 0.6.49-beta.1 — 原生手持與酒桶提示修復

- 移除謎之雞尾酒、深水炸彈、下界特調、冰葡萄的自訂固定手持模型。以 Java 原始物品貼圖的完整第一幀交給基岩原生物品渲染，保留既有原生 drink/eat 使用動作與完成使用事件。
- 酒桶進度只使用原生 actionbar，移除會在 0.6 秒後銷毀的重複文字層；凝視時每 10 tick 續顯，移開時只清除一次。保留名稱、數量、品質、剩餘時間與分隔空格。
- 世界名酒配對更新為 0.1.12-preview.1，繼續使用酒館共用機制。

## 已知限制與驗證範圍

手持與物品欄貼圖目前使用第一幀，**未還原 Java 的逐幀貼圖動畫**；放置後的既有動畫不變。沒有以固定姿勢的自訂模型替代原生動作。

資源、原作第一幀像素、原生使用元件、HUD 更新規則及隔離 BDS 載入均納入檢查。未模擬玩家；實際手持／飲用畫面與酒桶提示穩定性仍須客戶端驗收。BDS 載入成功不代表畫面驗收。

公開包依賴廚房 1.0.6。升級前備份世界，更新配對 BP/RP；UUID 與物品 ID 不變。
