# 0.6.67 beta 1

本版整合 2026-09-29 收尾的開放 PR，重點是常駐能效、懸掛酒杯架世界槽位，以及公開家族相容基線。舊 WIP PR 以歷史保留方式合併，沒有把舊 runtime 覆回主線。

- **常駐能效（#106）**：酒櫃／酒架展示維護改為有界批次與同櫃去重，避免無狀態變化時重複查詢／寫入；黑板文字改為 LRU 排版快取與字元差分修復；環境粒子先按維度與空間桶預篩選；自訂效果避免無效果玩家逐 tick 空轉與相同狀態重寫。確定性計數中，10 個滿櫃一輪維護的實體查詢由 900 降至 20、重複種類／旋轉／位置寫入由 2,700 降至 0。這些是 API 呼叫計數，不等同於實機 FPS／耗電百分比。
- **懸掛酒杯架（#107）**：移除東／西 facing 的歷史 `3-q` 腳本補償，恢復 Java 原版唯一契約——slot 0..3 永遠等於世界 X/Z 四象限；RP 同步修正 facing 1/3 的 bone visibility，使「看到哪一杯就取哪一杯」。BP 與 RP 必須成對更新，舊 RP 快取不能用來驗收。
- **家族相容（#97/#100）**：保留已驗證的 Deco ladder adapter、family candidate/native probe 與 vendor patch 工具；正式公開依賴由 Cookery **1.0.6 升至 1.0.8**。Creative catalog CI 改用目前 World Liquor 固定提交，避免舊家具分類快照造成假紅燈。
- **既有修補整理（#91/#94/#99/#102）**：碰撞／Tipsy 對齊、來源核對特效、破壞碎屑與材質音效、pickup/native storage、酒桶 97-tick cadence 等核心內容早已由後續主線吸收；本次保留其 PR 歷史但不回退後來的 Molang、觸控 aim、性能與存儲修復。
- 保留 0.6.66 的 Molang 複合賦值防回歸檢查、#105 東西向櫃架瞄準修復，以及所有現行 pickup／mechanics／effects／foundation 回歸。

驗收邊界：本版的自動化驗證不等於真實手機／平板渲染與性能量測。懸掛酒杯架需要客戶端重新下載新版 RP 後，以四 facing × 四掛點逐一觸控放取驗收；首次更新舊世界前仍建議備份。
