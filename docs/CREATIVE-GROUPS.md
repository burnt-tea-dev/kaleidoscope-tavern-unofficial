# 共用創造分類（0.6.46 / 世界名酒 0.1.9）

依照廚房本體慣例，自訂物品集中在「裝備」頁，以原生可展開的分類呈現。酒館本體和附屬共用分類名稱、代表圖標及順序。

| 順序 | 分類 | 內容 |
|---|---|---|
| 1 | 作物 | 葡萄、葡萄藤、野生葡萄藤與藤架 |
| 2 | 原料與調酒材料 | 果汁桶、蜂蜜瓶、龍息瓶、可樂、通寧水 |
| 3 | 釀造與調酒設備 | 果盆、酒嘴、酒桶、雪克杯、空瓶杯、冰櫃 |
| 4 | 酒飲 | 酒瓶與其他瓶裝飲料；品質分級品保留原來的創造代表品質 |
| 5 | 雞尾酒 | 可供飲用的杯裝成品 |
| 6 | 收納 | 酒櫃、酒窖櫃、酒架及杯架 |
| 7 | 家具 | 桌子、吧檯、沙發、高腳凳及附屬圓凳 |
| 8 | 燈飾 | 燈串與吊燈 |
| 9 | 裝飾 | 告示牌、黑板、掛畫、香薰及唱片 |
| 10 | 工具 | 梯具、莫洛托夫燃燒瓶 |

附屬食物繼續接入廚房的食物分類。顏色和木種保持各自連續的順序；兩個包合併後仍是同一分類。

分類由 `tools/creative/groups.json` 及各包 `data/creative-decoration-groups.json` 生成。附屬不能為同名分類換另一個圖標。物品 ID、配方、隱藏實作方塊及可見物品集合不變（酒館 160、世界名酒 66）。歷史檢查只還原已記錄的選單欄位，仍檢查其餘遊戲資料。

驗證：29 項分類資料測試；不模擬玩家或創造介面。
