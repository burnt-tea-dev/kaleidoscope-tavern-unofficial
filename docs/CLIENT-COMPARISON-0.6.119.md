# dot 的飲用對照場景：Tavern 0.6.119

參照 Java Tavern 1.2.0／NeoForge Minecraft 1.21.1 與 live 的同一飲品。
真人未驗收；微醺按使用者排除，其餘完整還原仍是目標。

1. Survival 手上放單瓶酒，背包另一格放空瓶×5，再飲用。Java 與本版都應
   在原手持欄位留下空瓶×1，另一格仍×5。單杯雞尾酒／其他格空杯也做一次。
   比較第一／第三人稱喝完後的手持物、實際返還數量與有無多餘提示。
2. Survival 帶中毒與另一項原生效果，飲用葡萄汁桶
   `kaleidoscope_tavern:grape_bucket`。預設 NeoForge HONEY cure 應只移除
   中毒；另一效果保持，手上留下空桶。Creative 也應治中毒，保留汁桶並
   取得一個空桶。第三方自訂 cure／取消事件尚未實作，另行記錄。
3. 以實際調酒機製完成一杯帶100%原生效果的特調；喝完確認效果確實生效
   並返還空杯。機率浮點邊界已由 Java 數值及註冊入口回歸驗證，不要求用
   重複大量飲用來估計極小機率差異。
4. 提前放開、切槽、交換手持物，確認未喝完時沒有套用完成效果／返還容器，
   接著喝另一飲品，確認舊使用沒有串到新飲品。比較同一場景的音效與動作。
