# 0.6.51-beta.1 — 修正飲品破壞掉落展示模型

隔離 BDS 1.26.51.1 重現：脚本取回／破壞交易清除酒瓶資料後，替換方塊仍會排入 onBreak 回呼，後備分支因此額外掉落展示模型物品。

- 共用方塊交易標記自己負責的替換，消耗其後一次破壞回呼，避免重複掉落；回滾也採同一處理。
- 酒瓶原生破壞僅回收已儲存的酒瓶物品，保留數量及每瓶品質，不再把內部展示方塊當作後備掉落。
- 本體與附屬共用此修正，酒杯及特調資料仍經既有回收接口處理。

實際 BDS 檢查通過：白蘭地、竹葉青原品質掉落，脚本酒瓶／酒杯移除無額外掉落，缺失資料不掉模型，同一格不同品質酒瓶完整回收，特調顏色／效果／材料資料保留。沒有模擬玩家；實際玩家挖掘手勢尚待客戶端驗收。

已經掉出的錯誤展示物品不會憑空補出原品質；本次阻止新增錯誤掉落。其餘既有未完成項目（精確微醺鏡頭 roll、原生手持貼圖逐幀動畫、九格酒櫃實際點擊驗收）狀態不變。

搭配世界名酒 0.1.14-preview.1、廚房 1.0.6；備份後同步更新 BP/RP。
