# 0.6.64 beta1 — 機制修復與 PR 整合

整合 #91、#93、#94、#95 的碰撞、龍頭容器、互動粒子與聲音修補；保留 0.6.63 指南、創造分類、中鍵拿取與附屬接口。不是全面 Java 1:1 驗收版。

## 本版修復

- 酒桶實際方塊回呼每 97 tick 扣除 97 tick，不再每 97 tick 只扣 20；加入實際註冊回呼回歸測試。品質 1→6 的持續載入純規則推算恢復 36,666 game ticks，並非 TPS/卸載的實時保證。
- 普通錯配原料可加入滿液酒桶並釀成醋；四槽、數量上限、先液體後原料和發酵鎖蓋仍保留。帶自訂資料的物品仍以拒收保護，不抹除其資料。
- 龍頭直接替換空瓶，保留朝向／品質，修復多掉空瓶；擴充放置容器、已註冊方塊產物及無歧義物品／方塊別名，失敗回滾。比較原生方塊使用維度與座標，不依賴 JS 物件相等。
- 尖嘯允許冒險模式施放，可命中 PvP 開啟時的生存／冒險玩家；創造／旁觀與世界 PvP 保護保留。恢復傷害呼叫後的加速度流程，移除任意 256 目標截斷。
- 經驗吸引使用原版 AABB 範圍與距離／方向公式，不再截斷 128 顆；保留真實經驗球與原生拾取／修補，不猜經驗值。
- 登頂改用原生固體／液體表面查詢，移除不相關的酒瓶支撐白名單，保留安全傳送與高度邊界。
- 莫洛托夫區分靈魂火／普通火，支援側面可燃鄰接及上半磚／倒置階梯，拒絕把任意非空氣（例如水）當承托。未知第三方形狀與傳送門點火仍有範圍限制。
- 接回 25 種酒、97 個瓶數形狀、杯、雪克杯與酒桶邊緣碰撞。微醺偏航預設關閉以免改準星，`function kt_tipsy_motion_on` 明確啟用近似表現；不是 Java 純鏡頭 roll。
- 感知先查實際效果登錄表，不再把無效 Glowing 呼叫當成已實現輪廓；倒置仍用 Java 同樣的 Grumm，原生支援時隱藏名稱。

## 驗證範圍

完整靜態發版檢查、固定 Java 來源／歷史 runtime 雜湊核對，及 **155 項**獨立腳本回歸測試（105 特效／龍頭 + 50 機制；19 項龍頭包含在 105 內，不重複加總）。腳本替身不是 BDS 或玩家驗收。

新增隔離 BDS 原生機制／碰撞 CI，使用真正方塊、物品、生物與時序，**不使用 SimulatedPlayer**。本版實際執行結果見 PR checks 與 `Tavern-native-mechanics-0.6.64` 證據，不以本段文字預先宣稱成功。沒有真人客戶端、觸控、多人 PvP、逐幀粒子或效能驗收。
