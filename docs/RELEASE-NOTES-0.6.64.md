# 0.6.64 beta 1

以 0.6.63 為基礎，整合已通過測試的四條修復線：

- **吊掛杯架取放**：改用實測的逐面命中基準（底面事件＝水平旋轉 180°、射線＝x 鏡像；東西面射線＝z 鏡像），並以朝向顯示映射定址格位；點哪個杯子就拿哪個，四個朝向一致。
- **窖藏酒櫃／酒架**：共用儲存路由套用同一逐面基準，東西朝向不再左右錯位（含世界名酒附屬酒櫃，因其生命週期由酒館托管）。
- **龍頭接酒**：原地替換載體，腳本轉換／移除／回滾繞開自然破壞回呼，不再多掉空瓶。
- **拿取對齊（PR #101）**：櫃架／瓶杯取物改走原生主手儲存與原生物品資料保存，附帶取物音效與持久化；共用測試基線以資料化 op 清單重建，任何未審查的位元改動仍會失敗。

驗證：foundation 231/231、tap 19/19、pickup 283/283、glassware 12/12、mechanics 8/8、effects 101/105（其餘四個需 CI 參考封存檔）、靜態檢查通過。尚未宣稱：雙端客戶端畫面驗收與模擬玩家測試。
