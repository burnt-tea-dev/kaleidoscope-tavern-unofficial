Independent work-in-progress source identity based on public Tavern 0.6.95.
This draft has not been merged, released or deployed.

The shaker ingredient HUD now covers all sixteen Java ChatFormatting colors.
Its three slots use 51 literal image controls, with 27 additional sprites
generated by multiplying the source rhombus mask while preserving alpha.
Existing seven color protocol indices, progress controls and expiry keys are
preserved for integration with the separate progress-fade repair.

Signature cocktails keep the existing 336 exact Java mixture atlas unchanged.
Arbitrary registered RGB values use the shaded white entry and a separate
multiplicative color-mask material, retaining source shading and the independent
untinted glass pass.

Focused source, protocol and texel checks passed: 4913 HUD/actionbar combinations,
4096 exact Java RGB mixtures, RESET exclusion, arbitrary RGB preservation,
48 nonempty slot sprites and six white fallback frames. The canonical baseline
release check passed. Native client rendering, Java pixel comparison and complete
family acceptance remain unverified.
