# 0.6.43 — 創造中鍵拿取與共用底層測試版

本次修復創造模式中鍵拿取內部方塊物品；配對 **世界名酒 0.1.6-preview.1** 使用。

- 家具與掛畫使用正確手持物品；本體／附屬由共用邏輯處理酒瓶、雞尾酒等內部放置 ID。
- 酒瓶保留實際品質，招牌雞尾酒保留配方與顏色，原版藥水保留種類；不消耗世界中的展示，不複製家具儲存內容。
- 同時納入共用酒櫃交易與效果生命週期、精簡 ActionBar 效果條、裝飾可摺疊分類。
- 原有物品／方塊 ID、存檔 UUID、材質和配方不變。

需求：Bedrock 1.26.50+、森羅物語本體 1.0.6；附屬需上述配對酒館版本。

**升級前備份完整世界。共用底層遷移後不要單獨降級其中一包。**

自動測試與完整打包檢查通過後發布。**本版本尚未經 Minecraft 客戶端或 BDS 真玩家驗收**，尤其需在世界副本確認原生中鍵事件與再次放置／飲用。冥視／寶藏感知等原本缺失行為不在本次修復範圍。
