# 0.6.50-beta.1 — 飲品表面、家具碰撞與指南顏色條件

- 為 22 個飲品模型內 82 個重合雙面加入 0.02 模型單位的微小厚度，處理杯底／液面閃爍。正反面的原作 UV 都保留，避免單面材質下背面消失。
- 16 色沙發的左右轉角恢復坐墊碰撞，側靠背改至模型實際所在側；座位上方留空。
- 修正三連黑板左右端的模型切片對應，保持已存文字與連接狀態。
- 雪克杯製作頁按 Java 原始配方顯示顏色標籤與品質要求；實際指定物品的槽位仍顯示物品。使用廚房現有的產品製作頁。
- 附屬可註冊調酒材料分類；世界名酒的可樂、湯力水不再列入雞尾酒。
- 酒架／酒櫃共用互動入口在滑鼠、手柄操作時採用原生視線命中座標；觸控保留原生點擊座標。增加事件／視線座標差異診斷，保持 Java 格位規則及舊存檔欄位。

## 驗證與限制

純資料檢查涵蓋 80 個酒架格位、32 種沙發轉角、黑板切片及三語指南。隔離 BDS 1.26.51.1 的原生射線驗證九格酒櫃四方向共 36 個位置，原版盔甲座物理探測涵蓋 32 個轉角區域；未模擬玩家。

尚未進行客戶端畫面／實際點擊驗收。九格酒櫃「左列取出右列」的實際點擊來源尚未確證；此次共用命中座標修正及診斷仍待該場景驗收，不能將格位公式檢查視為問題已根治。

上版原生手持／飲用動作方案保留，手持貼圖仍是 Java 原圖第一幀，逐幀動畫尚未還原。微醺的精確 Java 鏡頭 roll 仍未還原。

搭配世界名酒 0.1.13-preview.1、廚房 1.0.6；備份後同步更新 BP/RP。
