# Tavern 0.6.203

Incense uses its own native zombie-villager conversion with a three-second
countdown. The selected vanilla actor definitions and normal golden-apple cure
remain intact. Later incense damage is no longer skipped by a curing tag,
including tags already present on saved actors.

Registered callback and native-definition preservation regressions pass. Exact
native completion timing, reset behavior, saved-world restart and client sound
or visuals remain unverified for this release. See the
[current incense evidence](PARITY-MATRIX.md#香薰專用原生轉換2026-11-06來源已實作原生待驗).
