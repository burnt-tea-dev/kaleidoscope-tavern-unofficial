# 0.6.35-beta.1 — 生存入口、附屬接口與封包資訊

- 野生葡萄藤直接生成可採收的植株。搜尋範圍涵蓋樹冠下方，森林、平原與草甸中的橡樹／樺樹樹葉可成為附著點。移除不屬於 Java 流程的額外起始合成。
- 補齊基岩版雪塊、岩漿塊的種植土壤 ID。
- 行為包與資源包新增英語、簡體及繁體名稱與描述，並加入包圖標。
- 語言檔使用有效註解格式；投擲酒瓶增加缺失的第 26 種模型與材質映射。
- 附屬註冊接口支援外部六級品質酒、杯裝雞尾酒、酒架視覺及其自訂效果。指南可把附屬的配方與使用方法合併顯示。
- 針對大量附屬資料改用線性分包計算，避免載入時觸發伺服器看門狗。

驗證：酒館的靜態發行檢查通過；以基岩專用伺服器 1.26.51.1 同時載入 Cookery 1.0.6、酒館 0.6.35 與世界名酒 0.1.0 預覽包，腳本接口成功註冊。檢查只涵蓋載入，仍需裝置端驗收模型與互動。
