# 圖鑑、圓周酒架與爆炸修復

## 變更

- 按森羅廚房原生指南分工：工作站頁面說明操作；食物／飲品頁面使用原生「製作方法」入口。移除非食物條目的工作台配方與重複操作段落。
- 本體 12 種雪克杯配方納入指南；附屬的冷凍配方歸入成品條目。保留替代材料、品質限制、產量與冷凍時間，核查繁中、簡中及英文。
- 圓周酒架使用 Java 的 16 × 2 × 16 薄盤選取／碰撞範圍；四個朝向、六個槽位的可見瓶子與取酒槽位一致。
- 移除整類方塊的爆炸攔截與無敵抗爆值，依 Java 方塊設定抗爆值。世界名酒冰箱保留 Java 的 1200 抗爆值。
- 原生方塊破壞事件負責物品掉落、儲存資料及顯示實體清理；多方塊酒桶只掉落一次；附屬酒櫃沿用酒館共用處理。
- 修正原生水瓶的藥水投遞類型為引擎實際的 `Consume`，並驗證藥水身份可還原。

## 驗證範圍

靜態檢查涵蓋指南傳輸、三語、素材、歷史資源保留、Java 槽位座標與抗爆值。使用 BDS 1.26.51.1 隔離世界驗證原生爆炸事件，未使用模擬玩家。客戶端指南排版、觸控選位和整套第三方 UI 的顯示仍需遊戲內驗收。

## 安裝

配套使用酒館 0.6.48-beta.1、世界名酒 0.1.11-preview.1 與公開版森羅廚房 1.0.6，同時更新 BP 與 RP。UUID 與物品 ID 維持不變。

伺服器的燒烤胡椒樹方塊 ID 與第三方箱子 UI 修正屬另外的相容修補，不將私有第三方包放入本公開下載。
`header → version: invalid string` 尚未定位來源；現有伺服器 manifest 均為有效的數字陣列版本，需要原始報錯上下文或出錯包才能判定。
