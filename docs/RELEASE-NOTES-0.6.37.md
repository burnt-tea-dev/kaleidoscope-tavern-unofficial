# Kaleidoscope Tavern (Unofficial) 0.6.37 beta 1

This public test hotfix keeps the Java creative entry for Signature Cocktail. Java includes it in the cocktail tab; its appearance and behavior still need device review.

- Depth Charge and Mystery Cocktail now use their verified 16×16 item sprites, so the held and hotbar icons have static fallbacks on Bedrock.
- Watermelon juice no longer receives a wine quality tooltip. The guide now explains its melon tap source and that it has no aging grade.
- Dragon Breath Bottle and Honey Bottle are grouped with drinks; Molotov is grouped with cocktails instead of brewing equipment.
- World Liquor 0.1.3 preview 1 requires this Tavern version.

Static validation and isolated BDS load are recorded in `docs/VALIDATION-0.6.37.json`. Android rendering, interaction and resource-pack combinations still need in-game review.
