# HUD 去重已整合進酒館本體

自酒館 0.6.57 起，無須安裝獨立「酒館 HUD 去重相容補丁」。原補丁 UUID `22ec4381-6382-507c-a5e2-104c29b6a298` 可從世界資源包清單移除。

更新既有世界時，將酒館資源包移到原補丁的位置，保留其他包相對順序。原補丁同時整合酒館雪克杯資料與 Java Saturation 的 `!js.` 資料過濾；本體繼續保留這三個精確條件，不依賴該附屬。

僅隱藏雪克杯三槽／搖酒進度資料及 `!js.` 飽和度資料。一般提示、酒桶進度與拒絕原因保持可見。沒有 Java Saturation 時也可正常使用。沒有修改第三方包、隱藏整個 Actionbar 或修改原版玩家實體。

其他包若也改寫同名 HUD 控件，仍須檢查資源包優先順序；JSON UI 不會自動合併不同包的可見條件。腳本除錯器可檢查伺服器腳本，但無法替代客戶端 HUD 畫面驗收。

檢查：`node tools/check_actionbar_filter.mjs`。此檢查只驗證資料與規則，不宣稱已完成客戶端驗收。
