# managed-server Actionbar 去重層 1.0.2

放在 managed-server RP 清單最前方。針對已確認同時存在的酒館圖示 HUD 與 Java Saturation HUD，統一原版 Actionbar 背景及文字的可見條件。只隱藏雪克杯三槽封包、搖酒進度封包及既有 !js. 飽和度封包；一般訊息、酒桶與錯誤提示繼續顯示。

不更改或移除任何第三方包。依賴酒館 RP 0.6.56，所有啟用包更新時仍須通過完整依賴檢查。此包以現有組合為適用範圍，不應單獨套到沒有酒館圖示 HUD 的世界。

驗收：看向雪克杯只有一組圖示；搖酒只有圖形進度；材料不足等訊息可讀；看酒桶仍有狀態；一般 Actionbar 可讀；生存飽和度不露出 !js. 文字。
