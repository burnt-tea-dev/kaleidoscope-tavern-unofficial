# Repository scope

`main` is the C6 development baseline. It contains the runnable BP/RP (`runtime/`), implementation source/scripts, tests, source-locked recipe/data inputs, SDK/examples, documentation/history, and the minimal A17 art inputs required by the current build/test pipeline.

Large historical offline galleries, Blockbench editor exports, duplicate visual-lab packs, generated delivery archives, caches, and generated regression/TAP reports are intentionally not duplicated in Git history. They remain traceable in the C6 delivery archive and source-lock metadata; current runtime assets are committed directly.
