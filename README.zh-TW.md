## 當前維護基線：0.6.110

此來源 WIP 從公開主線重新整合雪克杯圖形消退、附屬材料分類、完整十六色 HUD 及招牌調酒 RGB；不是找回失落 T98 的原始檔。配對世界名酒 0.1.66 僅調整既有 0.1.58 的版本／依賴資料，仍待整合驗證。

森羅物語：酒館的非官方基岩版移植。本體可獨立安裝，不再強制依賴 Cookery；裝有 Cookery 1.6.0 時保留其指南章節及家族連動。

### 獨立指南

- 一本書與一顆酒館葡萄可合成酒館指南；也可在創造欄的釀造設備群組取得
- 原有酒館指南及配方書都直接開啟本地指南，不再被替換成 Cookery 指南
- 獨立入口與 Cookery 入口共用同一份內容，保留七大入口、單條目直達、多配方、顏色／品質條件及完整品質效果
- 支援繁體中文、簡體中文、英文；獨立指南可自行選擇語言

### 安裝與限制

使用 Bedrock 1.26.50 或更新版本，同時啟用酒館 BP/RP。可選安裝 Cookery；其他森羅附加包仍可能有自己的 Cookery 依賴，請使用配對版本。不要同時啟用不同作者的酒館包或舊版重複包。

升級前備份世界。酒館 UUID、物品／方塊 ID 及既有儲存資料格式保留；本次不自動部署 live 或遷移私人存檔。詳見 [安裝與遷移](docs/INSTALLATION.md)、[本次版本說明](docs/RELEASE-NOTES-0.6.80.md) 與 [維護基線](baseline.json)。

靜態檢查、BDS 載入／重啟與真實客戶端驗收分開記錄。微醺仍為 yaw 適配，尚未宣稱還原 Java 純鏡頭 roll。手持、触控及表單畫面仍需客戶端驗收。

代碼、美術及第三方字型依各自條款；保留 [原作與素材署名](CREDITS.md)。歷史版本結果不可代替本版驗收。

蹲下使用酒館指南可查看目前酒效，並切換原作圖示 HUD。圖示使用 UI Queue；反覆文字列仍預設關閉。
